# ClaudeDeck

並行して動かしている Claude Code のセッションを、一覧と詳細で見るツールです。

セッションを行き来していると、どれが自分の返事を待っているのか分からなくなります。
そして自分が何を答えたのかも思い出せません。

その2つを1画面で分かるようにしたものです。

## できること

- いま動いているセッションを一覧で出す
- どれが自分の返事待ちなのかを色で分ける
- 自分が選んだ選択肢と、その選択肢の説明を時系列で読み返せる
- 提出したプラン、却下したツール、使ったスキルも同じ時系列に並ぶ
- 文脈が圧縮された地点を出す。そこより前は Claude 側も覚えていません
- 何にトークンを使ったかを出す。どのツールが文脈を食っているかも見られます
- 画面から新しいセッションを起こして、そのまま会話を続けられる
- 途中でモデルや考える量を替えて、同じセッションの続きを起こし直せる
- 選んだセッションのターミナルを前面に出す
- 返事待ちに入ったことを Slack へ知らせる（設定したときだけ）
- その通知の設定を、画面の「設定」ボタンから変える。再起動は要りません
- 新しい版が出たら画面で知らせる。ボタン1つで入れ替わります

## 入れ方

次のページから `ClaudeDeckApp-win-Setup.exe` を落として、ダブルクリックしてください。

<https://github.com/iyotaA/claude-deck/releases/latest>

置き場所は聞かれません。
自分のユーザーフォルダーの中に入るので、管理者権限も要りません。

初回だけ、青い画面で止められることがあります。
署名を買っていないためです。
「詳細情報」を押してから「実行」を押すと進みます。

入れ終わると、そのまま画面が開きます。
次からはスタートメニューの ClaudeDeck から起動できます。

**Node.js は要りません。** 中に入れてあります。

### 入るもの

| 場所 | 中身 | 消えるとき |
|---|---|---|
| `%LOCALAPPDATA%\ClaudeDeckApp\` | アプリ本体 | アンインストールで消えます |
| `%LOCALAPPDATA%\ClaudeDeck\` | 設定・記録 | 消えません |

分けてあるので、アンインストールしても Slack の設定は残ります。
入れ直したときに、また設定しなくて済みます。

## 使っている技術

本体は Node.js とブラウザの標準機能だけで動きます。
**外部パッケージは1つも使っていません。**

| 層 | 使っているもの |
|---|---|
| サーバー | Node.js 18 以降・`node:http`（静的配信・JSON API・SSE） |
| 読み取り | `node:fs` / `node:fs/promises`（`fs.watch` ＋ 2秒ポーリング） |
| 更新の push | SSE（画面側は `EventSource`） |
| セッション実行 | `node:child_process`（claude CLI を裏で起こす） |
| 外へ出る通信 | Slack への POST だけ（`fetch`。設定したときだけ） |
| 画面 | バニラ JS（ESM）・素の CSS。ビルド無し |
| テスト | `node:test` ＋ `node:assert/strict` |
| Windows | PowerShell ＋ `.cmd` |
| 依存 | なし（`dependencies` は空） |

窓を出す部分と、更新を当てる部分だけは .NET 10（C#）＋ Velopack です。
本体（`src/` と `public/`）は、これが有っても無くても同じように動きます。
詳しくは [開発者向け情報](docs/development.md) にまとめてあります。

ビルド工程はありません。
保存して画面を読み込み直せば反映されます。
