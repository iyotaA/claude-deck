# 使い方

[README](../README.md) に戻る

## 起動する

スタートメニューの ClaudeDeck から起動します。

専用の窓が開いて一覧が出ます。
アドレス欄もタブも無い、アプリらしい見た目です。

ポートを変えたいときは、環境変数 `CLAUDE_DECK_PORT` を指定してください。
埋まっている場合は自動でずらします。

すでに起動しているときにもう一度押しても、二重には立ち上がりません。
動いているほうの窓が前に出ます。

## 一覧の見方

左に並ぶ色は、いまボールがどちらにあるかを表します。

- 赤 … あなたの番。質問待ち・プラン承認待ち・承認待ち・許可待ちのどれか。
  **答えるまで1行も進みません**
- 黄 … 返信待ち。Claude は応答を返し終えて止まっています。
  放っておいても壊れませんが、次の指示を出すまで動きません
- 青 … Claude の番。実行中
- 灰 … 終了。直近24時間のものだけ残ります

赤が並んでいたら、上から手をつければよい並び順になっています。

## 詳細の見方

一覧の行をクリックすると右側に出ます。

いちばん上に、このセッションを始めたときの指示が出ます。
「なんでこれをやっていたか」を思い出すための場所です。

その下の「あなたが決めたこと」に、質問と選んだラベル、その選択肢の説明が並びます。
選ばなかった案も畳んであるので、開けば比較できます。

時系列は「判断だけ」で絞り込めます。
Claude の説明が消えて、自分が動かした場面だけが残ります。

## PC を立ち上げたときに自動で動かす

**設定は要りません。** 入れた時点で登録が済んでいます。

次のログオンから、サーバーが裏で立ち上がります。
窓は出ません。見たいときにスタートメニューから開きます。

いまの状態は、画面の「設定」のいちばん下で見られます。

裏で動くぶん、画面に出ていた文字は次のファイルに残ります。

```
%LOCALAPPDATA%\ClaudeDeck\launcher.log
%LOCALAPPDATA%\ClaudeDeck\server.log
```

切り替えたいときは、次を実行してください。

```
"%LOCALAPPDATA%\ClaudeDeckApp\ClaudeDeck.exe" --uninstall-startup
"%LOCALAPPDATA%\ClaudeDeckApp\ClaudeDeck.exe" --install-startup
```

同じ実行ファイルに、他の操作もあります。

- `--status` … いまの状態をまとめて出す
- `--open` … 窓だけ開く
- `--stop` … 裏で動いているサーバーを止める
- `--background` … 窓を出さずに裏で立てる

### 前の方式から乗り換えるとき

フォルダーごとコピーして使っていた場合、スタートアップフォルダーにショートカットが残っています。

放っておくと古いほうも一緒に立ち上がり、2つのサーバーがポートを取り合います。
画面は出るのに設定が反映されない、という追いにくい形になります。

そこで、起動したときに自動で見つけて無効にします。
消さずに `ClaudeDeck.lnk.disabled` へ名前を変えるだけなので、戻すこともできます。

無効にしたときは、画面の「設定」に1行出ます。

## 新しい版に入れ替える

起動したときに、静かに確認しています。

新しい版があると、上のバーに帯が出ます。
「更新」を押すと、落として入れ替えて、勝手に起き直します。

窓は開いたままで構いません。
同じアドレスで戻ってくるので、そのまま使い続けられます。

途中で失敗したときは、その場で理由が出ます。
黙って元のままになることはありません。

いまの版は、上のバーの右のほうに出ています。
押すと確認の結果が読めます。

確認そのものを止めたいときは、環境変数を1つ立ててください。

```
setx CLAUDE_DECK_UPDATE_OFF 1
```

画面からは止められません。
自分で自分を締め出せる口は作らない、という決まりにしています。

## 画面からセッションを起こす

上のバーの「起こす」を押すと、その場で新しいセッションを始められます。
ターミナルを開かなくても、この画面の中だけで会話が進みます。

書くのは最初の指示と、始めるフォルダーの2つだけです。
モデルや上限は、決めたいときだけ触ってください。

起こしたセッションは、いつもの一覧と詳細にそのまま並びます。
記録の残り方も、ターミナルで動かしたものと同じです。

### 確認はこの画面に出ます

ここから起こしたセッションも、作業の途中で聞きに来ます。
ターミナルで出る「これを実行していいですか」は、詳細の「あなたの番」に出ます。

**答えるまで待ちます。** 放っておくと、そこで止まったままになります。
10分たっても答えが無いときは断ったことにして、次の指示を待つ形に落ちます。

選択式の質問も同じ場所に出ます。札を選んで「この内容で回答する」で送ります。
どれも当てはまらないときは「その他（自分で書く）」に書けます。

既定は plan モードです。読んで考えるだけなので、ファイルは書き換わりません。
プランが出たら「あなたの番」に承認のボタンが3つ出ます。
**押したボタンで、そのあとの権限モードまで決まります。**

| 押すもの | そのあと |
|---|---|
| Yes（auto） | Claude が判断して、危ないものだけ確認に来ます |
| Yes, auto-accept edits | ファイルの変更まで自動で通します |
| No（プランを直す） | 承認せず、理由を書いて差し戻します |

「承認したのにファイルが書けない」が起きないように、承認とモードの移動を1つのボタンに束ねてあります。

### 始められるフォルダーは決まっています

どこでも起こせるわけではありません。
選べるのは、そのPCで Claude Code が動いたことのあるフォルダーだけです。

足したいときは、環境変数 `CLAUDE_DECK_RUN_DIRS` にパスを書いてください。
複数あるときは `;` で区切ります。

ボタン1つでコードが動く機能なので、届く先を先に狭めてあります。

### かかるお金

起こしたセッションは、ターミナルで動かしたときと同じだけ使います。
押し間違いに備えて、既定で 20 USD の上限を掛けてあります。

上限に達すると、そこで止まります。
フォームの「上限」で 0.01 から 50 まで変えられます。

何にトークンを使ったかは、詳細の「数値」で後から見られます。

### 続ける・止める・替える

起こしたあとは、実行パネルの下の欄から次の指示を送れます。
Enter は改行で、送るのは Ctrl+Enter です。

「止める」は2回押しです。
1回目で見た目が変わり、もう1度押すと止まります。

いま走っている手だけをやめさせたいときは「割り込む」です。**こちらは1回押しで効きます。**
会話は生きたまま残るので、そのまま次の指示を打てます（ターミナルの Esc と同じ働きです）。
使える claude かどうかは向こうが名乗るので、**対応していない版では札そのものが出ません。**

入力欄の上の「/ コマンド」から、`/context` のようなスラッシュコマンドを選べます。
選ぶと入力欄の頭に入るだけで、**送られはしません。** 中身を見てから自分で送ってください。

入力欄のすぐ上に「いま plan mode / opus-5」のような札が出ています。
そこを押すと窓が開いて、権限モード・モデル・思考量・上限を選び直せます。
モデルは使ったことのあるものが並びます（そこに無い名前は「自分で入力」から渡せます）。

走っている最中に権限モードとモデルだけを替えたときは、**そのまま動いているものに効きます。**
止めも建て直しもしないので、いま進んでいる作業は続きます。
替えたことが向こうに届くまでの一瞬だけ「替えています…」と出ます。

思考量や予算も一緒に替えたとき、あるいは1往復を終えて止まっているときは、
いまの分を畳んでから、同じセッションの続きを起こし直します。

どちらの道でもセッションの ID は変わりません。
一覧も詳細も、開いていたリンクもそのまま使えます。

### 止まらないときの止め方

この画面から起こしたセッションは、ClaudeDeck の子として動きます。
ClaudeDeck を終了すれば、抱えている分もまとめて落とします。

それでも残ってしまったときは、実行パネルに出ている PID を使ってください。

```
taskkill /PID <PID> /T /F
```

会話の記録は Claude Code 自身が残しています。
途中で止めても、そこまでの分は一覧と詳細から読めます。

## 窓が狭いときの一覧

窓の幅が狭いと、一覧は左上のボタンの中にしまわれます。

押すと一覧が手前に出てきます。
セッションを選ぶと自分で閉じて、詳細が画面いっぱいに戻ります。

閉じ方は4つあります。
- 左上のボタンをもう一度押す
- 一覧の右上の × を押す
- 背後の暗いところを押す
- Esc キーを押す

## ターミナルを前面に出す

詳細の「ターミナルを前面に」を押すと、そのセッションの窓が前に出ます。

タブで複数セッションを開いている場合、窓は前に出ますがタブは選べません。
タブの切り替えだけ手動でお願いします。

すでにターミナルで動いているセッションへは、画面から指示を送れません。
動いている窓に文字を打ち込む仕組みが、公開されていないためです。
無理に真似ると、バージョンが変わったときに黙って壊れます。

続きを自分で打つために「再開コマンドをコピー」を用意しています。

新しく始めてよければ、画面から起こすほうが早いです。
そちらは公開されている入口を使うので、この心配がありません。
やり方は「画面からセッションを起こす」にあります。

## ターミナルだけで見る

窓を開かずに一覧だけ見たいときは、こちらを使ってください。

```
node cli.mjs          一覧を1回出す
node cli.mjs --live   3秒ごとに出し直す
node cli.mjs --all    終了したものも全部出す
```

インストールして使っている場合、`node` は同梱のものを指します。

```
set DECK=%LOCALAPPDATA%\ClaudeDeckApp\current
"%DECK%\runtime\node.exe" "%DECK%\app\cli.mjs"
```
