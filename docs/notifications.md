# 席を外しているときに Slack へ知らせる

[README](../README.md) に戻る

画面を見ていないと、セッションが止まったことに気づけません。
Slack へ飛ばしておけば、スマホで気づけます。

知らせるのは、あなたの返事で止まっている待ちだけです。
何が届くかは、あとの「何が届くか」にまとめてあります。

同じ待ちで二度は鳴りません。
待ちに入ってからしばらく続いていたときだけ送ります。
目の前にいてすぐ答えたぶんは、ここで消えます。

どの待ちで鳴らすかは、あとから画面の「設定」で選べます。

## 1. Slack 側で受け口を作る

`docs/slack-webhook-setup.html` をブラウザで開いてください。
画面つきの手順書があります。

飛ばす先は自分専用のチャンネルか、自分への DM にしてください。
**質問文がそのまま流れます。** 共有チャンネルは避けます。

## 2. 受け取った URL を ClaudeDeck に渡す

いちばん簡単なのは画面から入れる方法です。

上のバーの「設定」を押して、いちばん上の欄に URL を貼り、「保存」を押します。
再起動は要りません。その場で効きます。

保存した値は次の場所に入ります。

```
%LOCALAPPDATA%\ClaudeDeck\config.json
```

このファイルを直接書いてもかまいません。

```json
{
  "notify": {
    "slackWebhookUrl": "https://hooks.slack.com/services/...",
    "settleSec": 6,
    "idleMin": 2,
    "remindMin": 0,
    "detail": "full"
  }
}
```

手で書いた場合だけは、あとで ClaudeDeck を起動し直してください。
ファイルの見張りはしていないためです。

環境変数でも渡せます。

```
setx CLAUDE_DECK_SLACK_WEBHOOK "https://hooks.slack.com/services/..."
```

こちらは、画面でまだ設定していないときの初期値という扱いです。
画面から保存すると、そちらが勝ちます。

環境変数を入れたあとも起動し直しが要ります。
自動起動を使っている場合は `-Action stop` してから `-Action start` します。
ターミナルで `set` しただけの値は、裏で動いているサーバーには届きません。

## 3. 効いているか確かめる

いちばん早いのは「設定」の中の「テスト送信」です。
押すとその場で1通届きます。2分待つ必要はありません。

起動したときの黒い窓にも、1行増えていれば効いています。

```
ClaudeDeck
  http://127.0.0.1:4317/
  読み取り元: C:\Users\<あなた>\.claude
  Slack 通知: 有効（環境変数 / https://hooks.slack.com/services/T0AB…/B12…/****）
```

黒い窓が出ない自動起動のときは、次で見られます。

```
curl http://127.0.0.1:4317/api/health
```

`notify.enabled` が `true` なら効いています。
送った数・失敗した数・最後の失敗の理由も、ここに出ます。

URL は伏せた形でしか出しません。
そのまま人に見せても問題ありません。

## 変えられるところ

全部「設定」の中にあります。保存すればその場で効きます。

| 設定の名前 | 設定ファイル | 環境変数 | 既定 | 意味 |
|---|---|---|---|---|
| Slack Webhook URL | `slackWebhookUrl` | `CLAUDE_DECK_SLACK_WEBHOOK` | なし | これが入っているときだけ動きます |
| 落ち着き待ち | `settleSec` | `CLAUDE_DECK_NOTIFY_SETTLE` | 6 | 待ちに入ってから送るまでの秒数。0 ですぐ送る |
| 返信待ち | `idleMin` | `CLAUDE_DECK_NOTIFY_IDLE` | 2 | 返信待ちで送るまでの分。0 で返信待ちを送りません |
| リマインド | `remindMin` | `CLAUDE_DECK_NOTIFY_REMIND` | 0 | 放っておいたときの念押し。分で入れる。0 で無効 |
| 質問文 | `detail` | `CLAUDE_DECK_NOTIFY_DETAIL` | full | 「載せない」にすると質問文を送りません |
| 通知する状態 | `states` | なし | 全部オン | どの待ちで鳴らすかを1つずつ選べます |

**同じ項目が両方にあるときは、画面で保存したほうが勝ちます。**
環境変数は、画面でまだ設定していないときの初期値という位置づけです。

環境変数も立っている場合は、画面にその旨が出ます。
どちらの値が使われているのか、迷わないようにするためです。

質問の中身を Slack に流したくないときは、質問文を「載せない」にしてください。
どのセッションが待っているかだけが届きます。

うるさいと感じたときは「返信待ち」の分を伸ばしてください。
5 にすれば、5分席を外したときだけ鳴ります。

0 にすると、ほぼすべての通知が止まります。
実際に鳴っているのは返信待ちの経路だけだからです（次を参照）。

## いったん全部止めたいとき

環境変数を1つ立てると、設定に関係なく止まります。

```
setx CLAUDE_DECK_NOTIFY_OFF 1
```

これだけは画面より強い扱いです。
値そのものは画面が勝ちますが、機能ごと止めるのは環境変数からできます。

止めているあいだは、画面の「設定」にもその旨が出ます。
戻すときは環境変数を消して、起動し直してください。

## 何が届くか

届くのは、次の4つの待ちです。
「設定」の「通知する状態」で、1つずつ切ることもできます。

- 返信待ち … Claude が喋り終えて静かになった状態。2分たっても返事がなければ送ります
- 質問待ち … Claude が選択肢を出して止まっている状態
- プラン承認待ち … プランの承認を待っている状態
- 承認待ち … コマンドの実行許可を待って止まっている状態。
  この画面から起こしたぶんの「許可待ち」もここに入ります（画面から答えられます）

**ほとんどの通知は「返信待ち」として届きます。**

Claude Code は質問を出しているあいだ、その質問をログに書きません。
書かれるのは答えたあとです。
そのため ClaudeDeck からは、質問中も「喋り終えて静か」に見えます。

実際に困る場面（席を外している間に止まっている）は、どちらでも同じように拾えます。
届いたときの見出しが「返信待ち」になる、というだけの違いです。

承認待ちについては、Claude が自分で判断して進めた分は送りません。
あなたに聞きに来て止まっているものだけが届きます。

## うまく飛ばないとき

まず「設定」を開いてください。いまの状態と、送った数・失敗した数が上に出ます。
止まっている場合は、その理由もそこに出ます。

- 環境変数 `CLAUDE_DECK_NOTIFY_OFF` が立っていると、何を設定しても鳴りません
- URL が `https://hooks.slack.com/` で始まっていないと、動きません。別のあて先へ業務内容を送る事故を防ぐためです
- URL が消されていた場合は、1回試して止まります。理由は `/api/health` に出ます
- 会社のプロキシを通さないと外へ出られない環境では届きません。追加のパッケージを使わない作りのため、対応できていません
- ClaudeDeck が動いていなかった間に始まった待ちは、飛びません。起動した直後に見えていた待ちも、飛ばしません。毎朝ログオンのたびに昨夜ぶんが全部鳴るのを防ぐためです

## Webhook の URL の扱い

**この URL は鍵そのものです。**
持っている人は誰でも、あなたのチャンネルに書き込めます。

Claude との会話に貼らないでください。
貼ると会話ログに残り、消しても残り続けます。
画面の「設定」か、環境変数か、設定ファイルに直接入れてください。

いちど入れた URL は、画面には出てきません。
出るのは `T0AB…/B12…/****` のように伏せた形だけです。
そのまま人に画面を見せても問題ありません。
