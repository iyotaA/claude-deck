            ClaudeDeck について

            答える問いは2つだけ

            並行して動かしている Claude Code のセッションについて、 どれが自分の返事を待っているかと、 そのセッションで自分が何を判断したかを見るための画面です。

            安全のために決めてあること

            Claude Code が ~/.claude に書いたファイルを読むだけです。 このアプリがあそこへ書くことはありません。

            画面からセッションを起こしたときに動くのは Claude Code 本人です。 会話ログや作業フォルダへ書くのはそちらで、起こせるのは設定の「作業フォルダ」に足した場所だけです。

            受け付けるのは 127.0.0.1 だけです。 会話ログには仕事の中身が入るので、社内ネットからは見えません。

            このアプリが自分で書くのは %LOCALAPPDATA%\ClaudeDeck\ の下だけです（設定・ピンとメモ・更新の記録）。

            入れた版（ClaudeDeck.exe）は、ほかに Windows へ3つだけ登録します。 ログオン時の自動起動・通知の差出人「ClaudeDeck」・通知を押したときの開き口 claude-deck://。

            依存パッケージはゼロ。Node.js 18 以降の標準モジュールだけで動きます。

            画面は3つのモード

            作業台 — いま動いているものを見て、答える場所。

            書庫 — 終わったものも含めて、過去を探す場所。

            数値 — セッションを跨いで、何が文脈を食っているかを見る場所。

            左のレールの絵か、数字キーの 1 2 3 で移ります。

            左のレール

            どのモードでも左端に出ます。上から作業台・書庫・数値・今日のまとめ、 下に枠の使用率の輪と、設定・このアプリについて。絵に触ると名前が出ます。

            作業台の絵の赤い数は、答えないと1行も進まないセッションの数です。 無いときは数を出しません。

            作業台は4つ

            上のバー — いまの場所・探す欄（Ctrl+K と同じ）・起こす。

            左の一覧 — いちばん上の枠「あなたの番」に、あなたの返事を待っているもの （許可・質問で止まっているものと、返信待ち）がまとまります。その下にピン留め、実行中、終了。 終了はたたんであり、見出しの右の ＞ で開きます。 一覧は左上のボタンで開け閉めでき（閉じても同じ場所に残ります）、頭の右の「すべて｜稼働中」で終わったものを隠せます。

            中央の詳細 — 頭、入力欄、タブ（経過・成果・いま・調査）の順。 頭の左に題・状態・置き場所、右上に ☆・メモ・数値・再開コマンドのコピーと、次の一手（ターミナルで返事をする など）。 答えないと進まないものはタブのすぐ下に、どのタブを見ていても出ます。 このセッションの目的は「いま」の先頭にあります。「拡大」で大きく開けます。

            右の紙 — そのセッションの数値と診断。頭の右上の数値の絵で出し入れし、紙の頭で数値と診断を切り替えます。 広い窓では最初から開いていて、開け閉めは覚えます。狭い窓では閉じて始まり、下から出ます。

            キー操作

            • CtrlKやりたいことを打って探す
            • 123作業台・書庫・数値へ移る（入力欄の外で）
            • ↑↓一覧のセッションを移る
            • CtrlEnter指示を送る・セッションを起こす
            • Esc開いている窓を閉じる
            • ←→列の境目を掴んでいるとき、幅を変える（Home で既定へ）

            開き方は URL で人に渡せます

            いま見ているセッション・モード・隠している種類・検索語は、そのままアドレスに乗ります （?session= ?mode= ?hide= ?tq=）。 そのまま送れば、相手も同じ画面で開けます。

            起こす・答える

            上のバーの ＋起こす で、作業フォルダに新しいセッションを起こせます。 この画面から起こしたもの（一覧の札「画面」）は、許可や質問にここから答えられ、 止める・モデルを替えて続けるもできます。

            ターミナルで動いているものは、窓を前に出すところまでです。

            待ちを順に片づける

            拡大で開いているとき、頭の ← 前／次の待ち → で、 許可・質問で止まっているセッションを一覧と同じ順に回れます（返信待ちは回りません）。

            通知

            答えないと進まないセッションが出たら、Windows の通知と Slack で知らせます （設定の「通知」で選べます）。Windows の通知を押すと、そのセッションを開きます。

            ピン留めとメモ

            詳細の頭の ☆ でピン留め、✎ でひとことメモ。 ピンを付けたものは終わっても一覧の「ピン留め」に残ります （返事を待っているあいだは「あなたの番」に入り、☆ が付きます）。メモはこの PC だけに置きます。

            今日のまとめ

            左のレールの 今日のまとめ、書庫の頭のボタン、Ctrl+K のどれからでも開けます。 その日に決めたことと書き換えたファイルを1枚に並べ、Markdown でコピーできます。

            一覧の点 — いま誰の番か

              一覧の行に足されるもの

              • ピン留め終わっても一覧の「ピン留め」に残します。「あなたの番」に入っているあいだは行の右に出ます
              • メモ自分で書いたひとこと。行の右の絵に触ると読めます（詳細の頭にも出ます）
              • 4/7いま何をしているか動いている行だけの2行目。TODO の進みと、いま走っている手。 許可・質問で止まっている行の2行目は、何を求めているか（ツールと中身）

              左のレールの輪 — 枠の使用率

                外側の輪が5時間ごとの枠、内側の輪が7日の枠。真ん中の数は高いほうの割合（%）です。 アカウントで1つなので、レールにだけ出します。読めていない枠は輪の溝だけになります。 古い値は輪を薄くし、触ると「いつ測ったか」が出ます。

                経過の印

                  札

                    実消費

                    入力・出力・キャッシュの読み書きに、それぞれの重みを掛けて足した数です。 キャッシュから読んだぶんは軽く、書き込みと出力は重く数えます。 請求額ではありません。

                    文脈

                    その要求の時点で Claude が抱えていた量です。圧縮が入るとここが落ちます。

                    キャッシュ命中率

                    読み直さずに済んだ割合です。モデルが混ざっていると出せません （数え方が違うため）。上でモデルを1つ選ぶと出ます。

                    古い N 本より ±x%

                    概要の札に添える差です。読んだセッションを時刻で前と後ろに半分ずつ分け、 1本あたりで比べています。多いのが悪いとは限りません（長く働いた日かもしれません）。

                    スキルの割合は「原因」ではありません

                    Claude Code が要求ごとに付けた帰属ラベルで数えています。 そのスキルの文脈下で走ったという意味で、そのスキルのせいで増えたという意味ではありません ―― 重かったのは仕事の中身かもしれません。

                    足しても 100% に届かないのは、どのスキルにも紐づかないぶんが残るためです。
